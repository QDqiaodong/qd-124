## 1. 产品概述

包装车间金属支架档案系统，核心维护支架与封口生产设备一对一配套绑定关系，支持多支架关联单台设备。系统围绕设备配套关联批量绑定展开，无标签维护、无历史溯源模块。

- 目标用户：包装车间设备管理人员、生产调度人员
- 核心价值：规范化支架与封口机设备的配套管理，提高设备配套调整效率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 管理员 | 系统内置 | 支架档案CRUD、设备绑定/解绑、批量绑定操作、设备清单查看 |

### 2.2 功能模块

1. **支架档案管理页**：支架列表、新增、编辑、删除
2. **设备配套清单页**：设备维度分页清单、支架汇总查看、单个绑定/解绑
3. **批量绑定页**：多选支架勾选组件、统一绑定到目标设备

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 支架档案管理 | 支架列表 | 分页展示支架名称、型号、长宽尺寸、当前绑定设备 |
| 支架档案管理 | 新增/编辑支架 | 表单录入名称、型号、长(mm)、宽(mm) |
| 支架档案管理 | 删除支架 | 删除支架档案，自动解绑关联设备 |
| 设备配套清单 | 设备分页列表 | 分页展示封口设备编号、已绑定支架数量、配套支架清单 |
| 设备配套清单 | 单支架绑定 | 为单个支架选择并绑定目标设备 |
| 设备配套清单 | 单支架解绑 | 解除支架与当前设备的绑定关系 |
| 批量绑定 | 支架勾选列表 | 可搜索、可分页、可多选的支架勾选专用组件 |
| 批量绑定 | 目标设备选择 | 下拉选择目标封口设备编号 |
| 批量绑定 | 批量绑定执行 | 一键将所有勾选支架绑定至同一台设备 |

## 3. 核心流程

### 支架建档流程
1. 管理员进入支架档案管理页
2. 点击新增支架
3. 填写名称、型号、长宽尺寸
4. 提交保存，档案入库

### 单支架绑定流程
1. 管理员进入设备配套清单页
2. 找到未绑定的支架
3. 选择目标设备编号
4. 确认绑定

### 批量绑定流程
1. 管理员进入批量绑定页面
2. 在支架勾选组件中勾选多件支架
3. 从下拉框选择目标封口设备
4. 点击批量绑定按钮，执行批量关联

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：工业蓝 `#1E40AF` 搭配沉稳灰 `#374151`，体现工业设备管理的专业感
- **辅助色**：警示橙 `#F59E0B`（解绑操作）、成功绿 `#10B981`（绑定成功）
- **按钮风格**：直角矩形、中等圆角 `radius: 6px`，实心主按钮 + 描边次按钮
- **字体**：系统默认无衬线字体，标题加粗，正文 Regular
- **布局风格**：顶部导航栏 + 左右结构内容区，卡片式列表展示
- **图标**：简洁线性图标，与工业管理场景匹配

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 支架档案管理 | 顶部工具栏 | 搜索框、新增按钮、数据统计卡片 |
| 支架档案管理 | 数据表格 | 列：名称、型号、长、宽、绑定设备、操作 |
| 设备配套清单 | 设备卡片列表 | 每卡片展示设备编号、支架数、展开查看支架详情 |
| 设备配套清单 | 操作区 | 绑定/解绑按钮、绑定设备选择弹窗 |
| 批量绑定 | 左侧支架勾选 | 可搜索分页表格，首列复选框 |
| 批量绑定 | 右侧操作面板 | 已选数量展示、目标设备下拉、批量绑定按钮 |

### 4.3 响应式

桌面端优先设计，主内容区最小宽度 1200px。批量绑定页面左右分栏在小屏下自动切换为上下布局。
