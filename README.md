# 封口机固定支架设备配套绑定管理系统

## 项目简介

包装车间金属支架档案系统，维护支架与封口生产设备的一对一配套绑定、解绑和批量绑定记录。

支持为每台封口机维护配套规则：最大支架数量、允许型号、长度/宽度范围。单个绑定与批量绑定前先按规则逐项校验，
展示通过项、冲突项及冲突原因，确认后仅绑定通过项。规则修改立即生效于后续绑定，不改动已有绑定。

车间换线时支持「换线改挂」：选择源设备上已挂的支架与目标封口机，先按目标机现行型号、长宽与容量规则逐项预检，
确认后通过项在同一事务内直接改挂到目标机（全程保持已绑定，不经过先解绑再绑定的未绑定中间态），冲突项仍留在源设备。
改挂完成后支架档案、设备清单占用与未绑定统计刷新一致。

## 换模批次放行联锁

换模后必须在「设备配套清单」为封口机**写下当前模具批次**（批次号 + 模具型号，模具型号必须在该机的「允许模具型号清单」内）：

- 未写当前批次、或当前批次模具型号不在该机允许清单时，**批量挂接与换线改挂一律拦截**（预检整单判为冲突，确认接口同步强制）。
- 写批次成功后，设备配套清单立即显示当前批次；批量绑定页、换线改挂页选择目标机时显示当前批次与放行状态。
- 每台设备保留完整历史换模记录，可按设备倒序翻看（仅最新一条标记「当前批次」）。
- **放行只认当前（最新）批次**：换新批次后旧记录只作历史追溯，永不再作为放行依据；当前批次型号被移出允许清单同样立即拦截。
- 单个支架绑定不走批次闸门，仅批量挂接与换线改挂强制联锁（后端硬校验，前端提示无法绕过）。

## 首件尺寸确认单

换完模具准备放量时，调度在「首件尺寸确认」页为机台单独开一张首件尺寸确认单：

- 开单写清**机台、模具批次（自动带出该机当前批次并快照留痕）、标准/实测长宽高、公差、开单人**；未登记当前模具批次的机台不能开单。
- 系统按「量差 = 实测 − 标准」逐维度计算，任一维度 |量差| > 公差 即判**超线**（恰好在公差线上不算超线）。
- **超线的单永远不能放行量产**（前端不显示签放入口，后端签放接口同步硬拦截），只能**退回再量**；退回为终态，重新测量需另开新单。
- 量差合格的待签放单由签放人签字放行；签放人/签放时间、退回人/退回时间全部落库留痕。
- 列表可按**机台**和**放行结果**（待签放/已放行/已退回再量）组合筛选；点开详情能看到谁签的、几点签的。
- 全部记录持久化在 MySQL `first_article_inspection` 表，关掉页面再进记录仍在，不再依赖交接口头传递。


## 技术栈

- 前端：Vue 3、Vite 5、TypeScript、Element Plus、Axios
- 后端：Spring Boot 3、JDK 17、Spring Data JPA、Spring Data Redis、Maven
- 数据：MySQL 8、Redis 7
- 部署：Docker Compose、Nginx

## 端口说明

| 服务 | 地址 |
| --- | --- |
| 前端 | http://localhost:3124 或 http://127.0.0.1:3124 |
| 后端 API | http://127.0.0.1:8124/api |
| MySQL | 127.0.0.1:3424 |
| Redis | 127.0.0.1:6424 |

端口来自根目录 `.env`，Docker 端口只绑定 `127.0.0.1`。

## 启动方式

```bash
cd qd-124
docker compose up -d --build
```

本地拆分验证：

```bash
cd backend
mvn compile -q
mvn test

cd ../frontend
npm ci
npm run build
npm test
```

后端测试（JUnit 5 + Mockito）覆盖热门型号 Redis 缓存在支架新增、改名、删除后的失效逻辑，以及 Redis 异常不影响支架保存的降级路径；另含换线改挂端到端测试（预检按目标机规则分项、确认后通过项一次改挂且冲突项留在源设备、全程无未绑定中间态），换模批次登记与放行联锁端到端测试（未写批次/型号不在允许清单时批量挂接与改挂整单拦截、换新批次后旧记录不再放行、按设备翻历史），以及首件尺寸确认单端到端测试（未登记当前批次不能开单、量差/超线计算与公差线边界、超线单签放硬拦截只能退回再量、签放/退回签字人与时间留痕、按机台与放行结果组合筛选）。前端测试（Vitest + Vue Test Utils）回归支架档案操作后型号建议刷新、绑定/规则页型号建议实时性、改挂预检请求、确认后设备占用刷新，换模批次登记/历史弹窗与批量绑定批次闸门前端拦截，以及首件确认单列表筛选传参、超线单只退不放、开单实时量差预警、签放/退回后列表刷新与详情签字信息展示。

## Docker 构建说明

Docker Compose 构建前端 Nginx 镜像和后端 Spring Boot 镜像，并启动 MySQL、Redis：

```bash
docker compose up -d --build
docker compose ps
```

## 常见问题

- 端口被占用：修改 `.env` 对应端口并重新启动。
- Maven 编译失败：优先检查 JDK 17、Lombok 版本和 annotation processor。
- 页面运行时接口失败：构建通过后检查后端容器日志、数据库连接和 Nginx `/api` 转发。
